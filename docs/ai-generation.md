# 🤖 AI Генерация новостей

## Как это работает

1. **Сбор RSS** — каждый час (или по расписанию) собираются новости из RSS-лент
2. **Дедупликация** — проверка на дубликаты по заголовку, ссылке и содержимому
3. **AI рерайт** — DeepSeek API переписывает новость с сохранением фактов
4. **Сохранение** — новость сохраняется в базу со статусом PENDING
5. **Модерация** — администратор подтверждает или отклоняет новость
6. **Автоподтверждение** — новости старше 1 часа подтверждаются автоматически

## AI модель

- **Провайдер**: DeepSeek API
- **Модель**: deepseek-chat (v4-flash для проверки статуса)
- **Temperature**: 0.7
- **Max tokens**: 1000
- **Формат ответа**: JSON

## Промпт

AI получает оригинальную новость и инструкцию:

```
Сделай рерайт новости на русском языке. Сохрани все факты, но полностью измени формулировки и структуру текста.

ОРИГИНАЛЬНАЯ НОВОСТЬ:
Заголовок: {article.title}
Источник: {article.source}
Текст: {article.content}

Создай новую статью в формате JSON:
{
"title": "Новый заголовок (до 100 символов)",
"summary": "Краткое описание (2-3 предложения)",

"tags": ["тег1", "тег2", "тег3"],

}
```

## Дедупликация

Проверка дубликатов на нескольких уровнях:

1. **Точное совпадение заголовка** — полный дубликат
2. **Совпадение по ссылке** — та же новость из того же источника
3. **Частичное совпадение** — >70% схожести заголовка
4. **Ключевые слова** — 3+ общих ключевых слова

Также проверяются дубликаты внутри одного батча RSS (локальная дедупликация).

## Расписание (Cron)

По умолчанию: каждый день в 5:00 и 18:00 по Москве.

```typescript
cronSchedule = '0 5,18 * * *'
```

Можно изменить через админ-панель (суперадмин → кнопка "Расписание").

Формат: стандартное cron-выражение (минута час день месяц день_недели).

## Статусы новостей

```
RSS → AI рерайт → PENDING → PUBLISHED
                    ↓           ↓
                 REJECTED    ARCHIVED
```

- **PENDING** — ожидает модерации
- **PUBLISHED** — опубликована
- **REJECTED** — отклонена модератором
- **ARCHIVED** — в архиве (старше 30 дней)

## Валидация контента

AI-новости проходят валидацию перед сохранением:

- Контент не короче 50 символов
- Заголовок не содержит fallback-фраз ("Контент находится в процессе генерации")
- Категория из списка разрешённых
- JSON ответа парсится с fallback-стратегией при ошибках
